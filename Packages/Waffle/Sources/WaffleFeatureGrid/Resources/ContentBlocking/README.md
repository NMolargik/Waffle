# Bundled content-blocking lists

`ads.json.zlib`, `privacy.json.zlib`, `cookies.json.zlib` are WebKit content-blocker rule lists
(raw-DEFLATE-compressed JSON) generated by `Scripts/build_blocklists.py` from:

| File | Source list | Upstream license |
|------|-------------|------------------|
| ads | EasyList — https://easylist.to/easylist/easylist.txt | dual: GPL v3+ / CC BY-SA 3.0 |
| privacy | EasyPrivacy — https://easylist.to/easylist/easyprivacy.txt | dual: GPL v3+ / CC BY-SA 3.0 |
| cookies | Easylist Cookie List — https://secure.fanboy.co.nz/fanboy-cookiemonster.txt | CC BY 3.0 |

The converted files are derivative works. Under CC BY-SA 3.0 they remain under CC BY-SA 3.0
(attribution to the EasyList authors, https://easylist.to); the rest of Waffle is not affected
because the lists are shipped as separate data files. Attribution is shown in Settings →
Content Blocking. `manifest.json` records each source's version.

The converter keeps only what WebKit can express (domain/URL network rules with type,
third-party and domain options, exceptions as `ignore-previous-rules`, and plain-CSS element
hiding). Scriptlet, redirect, `$removeparam`, extended-CSS and regex filters are skipped.

## Updating (do this before each release, or whenever)

```
python3 Scripts/build_blocklists.py --fetch      # downloads lists into ./.blocklist-src (gitignored)
cd Packages/Waffle && swift test                 # bundledListsDecompressAndParse sanity-checks them
```

The compiled-list identifier includes the source version (`waffle-<id>-<version>`), so users
recompile once after an update and stale compiled lists are removed automatically.
A list may hold at most 150,000 rules; the script aborts above 140,000.
